Концепт лендинга магазина в стиле Balenciaga. Делал для себя, чтобы прокачать анимации и работу с 3D. Проект неофициальный, к бренду отношения не имеет.

Демо: https://mazerexzy.github.io/balenciaga-lending/

Что внутри:

- первый экран с анимированным фоном и эффектом пыли на three.js
- слайдер товаров и карточки
- появление текста и счётчики при прокрутке на framer-motion
- плавный скролл на lenis

## Запуск

```
npm install
npm run dev
```

Сборка `npm run build`, сайт лежит на GitHub Pages в ветке `gh-pages`.
